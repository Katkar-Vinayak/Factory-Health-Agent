## 2. Backup Demonstration: Normal Machine Operation (1 Minute)

To demonstrate that the system does not produce false alarms on healthy machines:

1. **Navigate to M_001 (Welding Robot 1)** or stay on M_003.
2. In the **AI Factory Investigation** section, click **Normal Scenario**.
   - Timestamp sets to `2023-01-01 00:00:00`.
3. Click **"Analyze with Factory AI"**.
4. **Observe the Nominal Results**:
   - Executive Callout: **LOW RISK — Operating Within Nominal Boundaries**.
   - Failure Probability: **0%**.
   - Anomaly Status: **Normal Inlier** (Isolation Forest).
   - Agent Trace: Fast 3-step short-circuit path (*Monitoring Agent analyzed sensor data* → *Normal operation detected* → *Report Agent generated final report*).
   - No unnecessary deep root-cause investigation is triggered for healthy equipment.

## 3. Emergency & Offline Handling Talking Points

- **Zero LLM Dependency for Core Safety**:
  - If Wi-Fi fails or Gemini/OpenAI API quota limits are hit, the system automatically falls back to its deterministic rule engine and scikit-learn models without crashing or blocking.
  - High-confidence RCA, numerical evidence, and decision support remain 100% operational.
- **Backend Disconnection Resilience**:
  - If network connectivity to port 8000 drops, the frontend cleanly presents *"Unable to Connect to Industrial Backend"* with a retry button instead of a white screen or React error.
